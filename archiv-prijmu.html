🔑 Potřebuješ GitHub token pro ukládání DMT a nových dodávek.
1. Otevři github.com → Settings → Tokens → New token
2. Zaškrtni repo → klikni Generate → zkopíruj token (začíná ghp_)
3. Vlož sem a ulož — jednou, zůstane v prohlížeči
